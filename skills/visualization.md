# Visualization Skill

Prefer visual responses:
- **Markdown tables** for transaction lists, member comparisons, penalty summaries.
- **Charts** via artifact blocks for trends (monthly contributions, penalty counts).

## Artifact format
```artifact:table
{"title":"...","headers":[...],"rows":[[...]]}
```

```artifact:chart
{"title":"...","type":"bar","data":[{"name":"Jan","value":5000}]}
```

Offer download of tables (Excel/PDF) and charts (PNG/PDF) when presenting financial evidence.
